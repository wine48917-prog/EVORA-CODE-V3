# EVORA CODE V3 — Black Silver Edition

A mobile-first coding workspace starter built with vanilla HTML, CSS and JavaScript.

## Run locally
- Open `index.html` in a modern browser, or serve this folder with a local web server.
- The editor supports starter files, editing, local autosave, preview, a terminal/status panel, and source export.

## Included
- Black / silver responsive UI
- Separate developer sidebar and five-section bottom navigation
- File explorer, create-file flow, code editor and live HTML/CSS/JS preview
- Local browser storage
- EVORA AI interface placeholder
- App icon and PWA manifest

## Important limitations
- EVORA AI is a UI placeholder; it does not call a live AI model yet.
- The workspace is stored in this browser's local storage. Export your source regularly.
- This is the web project ZIP, not a compiled Android APK.

## Android APK (next stage)
Use Capacitor after testing and hosting the web build:
1. Install Node.js and Android Studio.
2. Add Capacitor to a build setup or wrap the hosted app.
3. Configure Android package ID and app icon.
4. Build and sign the APK in Android Studio.
